AUDATHAM — PLAIN HTML, CSS & JAVASCRIPT WEBSITE

This version does not use React, TypeScript, Vite, Node.js or npm.

FILES
- index.html: complete website layout and sections
- css/style.css: design and responsive/mobile styling
- js/products.js: all 39 products, package sizes, prices and original product image names
- js/app.js: product search, category filters, sorting, product details, basket, LocalStorage and WhatsApp checkout
- images/: original image assets extracted from the supplied AUDATHAM project
- robots.txt and sitemap.xml: basic search-engine files

HOW TO PREVIEW
1. Extract this ZIP.
2. Open the folder in VS Code.
3. Open index.html in your browser, or use the VS Code Live Server extension.
4. No npm install or build command is required.

HOW TO HOST
Upload index.html, css, js, images, robots.txt and sitemap.xml to the website root folder (for example public_html). Keep the folder structure unchanged.
